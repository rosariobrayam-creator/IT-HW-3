Web Page Do’s and Don’ts

Five habits to build into every page, and five to leave behind.

5 Things to Do

  • Use semantic elements like <header>, <nav>, <main>, and <footer> so the page structure is clear.
  • Add alt text to every <img> so the image makes sense to people who can’t see it.
  • Keep headings in order: one <h1>, then <h2>, then <h3>.
  • Give every page a descriptive <title> and the viewport <meta> tag.
  • Put styles in an external CSS file and write descriptive link text.

5 Things to Avoid

  • Deprecated tags such as <font>, <center>, <marquee>, and <blink>.
  • Using <table> to lay out the whole page; tables are for data.
  • Using <br> tags or empty paragraphs to create spacing; use CSS margins instead.
  • Vague link text like “click here.”
  • Low-contrast text and background colors that are hard to read.
